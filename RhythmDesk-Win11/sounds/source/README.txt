RhythmDesk built-in recordings · TimGM6mb-derived sample data

TimGM6mb.sf2 is copyright Tim Brechbill (2004) and David Bolton (2010).
The original soundfont, extraction script and resulting sample data are
distributed under GPL-2.0-only. The full license and upstream provenance
are included in this folder. Run Python 3 extract.py to regenerate
../recorded-samples.js from the included soundfont.

The Bell track uses the Cowbell sample. The Shekere track uses Cabasa as
a substitute. The Djembe, Kenkeni, Sangban and Dundunba drum voices mix
sampled Conga, Bongo or Taiko attacks with tuned synthesized bodies.
The Djembe bass (B) uses a separate user-supplied recording.
The remaining drum voices are approximate sounds for practice. An imported WAV for any
individual stroke takes precedence over these built-in sounds.
