RhythmDesk 1.65 · iPhone 离线版

把本目录的内容原样部署到同一 HTTPS 静态站点或子目录。
联网用 Safari 打开地址，进入「离线使用」，等待「1.65 离线资源已校验」。
点 Safari 分享 → 添加到主屏幕 → 打开为网页 App（如有此开关）。
首次从主屏幕打开时保持联网，在该窗口再次确认「1.65 离线资源已校验」。
先点「试开离线副本」验证浏览器从缓存打开编辑器。之后可用飞行模式验证：关闭 Wi-Fi，关闭网页 App，再从主屏幕打开。

编辑器、内置音色与导出功能已随页面打包。鼓谱和自导入音色仍由设备本地保存。
主屏幕网页 App 可能使用独立存储。可通过 .rhythm.json 导出、导入鼓谱。
清除网站数据后需联网重新下载离线资源。内置采样来源及许可见 sounds/source。

RhythmDesk-iPhone-Offline.html 是可单独分发的完整 HTML 文件。
电脑浏览器可直接打开。iPhone「文件」的 HTML 预览可能不运行脚本，
在 iPhone 上完整使用请通过上述 Safari 网页 App 方式启动。

升级已有主屏幕版本时在原 HTTPS 地址覆盖完整目录，保留原作用域；联网重新打开，看到 1.65 的首页版本与离线校验提示后再断网。
